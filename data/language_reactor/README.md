# Language Reactor YouTube sources

A snapshot of the first 50 YouTube channel recommendations Language Reactor displayed for French and English on 2026-09-23.

- `youtube_search_url` is a direct YouTube search for the channel name, deliberately kept instead of guessing an `@handle` or a canonical channel ID.
- `language_reactor_displayed_count` is the number shown beside that channel in Language Reactor's sidebar. The product does not document what that number measures, so it is preserved verbatim rather than interpreted.
- Recommendation order is per-language and may change in Language Reactor.

Use the catalog URLs in the CSV to refresh this snapshot.
